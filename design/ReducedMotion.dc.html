Motion system · reduced motion

Every animation has a resting state that is the whole design.

The rule that makes this safe: the resting state is the CSS default and animations only travel to it. Turning motion off can never hide content, because nothing is hidden to begin with.

This closes a real gap. There is currently no @media (prefers-reduced-motion) block anywhere in app/globals.css, and no matchMedia guard around the GSAP effect — while PRODUCT.md commits to WCAG 2.2 AA with “reduced-motion alternatives for animated interactions.” Today a visitor with the OS setting on still gets the full scrub.

The implementation

@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }

  /* the inversion becomes a per-section switch */
  .page       { --night: 0 }
  .zone-night { --night: 1 }
  .thr__scan  { clip-path: inset(0) }

  /* everything else pinned to its settled value */
  .hero-word  { font-variation-settings: "wght" 760 }
  .contact h2 { font-variation-settings: "wght" 620 }
  .rail__trail{ transform: scaleY(1) }
  .wf__span   { transform: scaleX(1) }
  .edge, .draw{ stroke-dashoffset: 0 }
  .packet     { offset-distance: 100% }
  .read w     { color: var(--ink) }
}
