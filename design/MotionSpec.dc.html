Motion system · implementation spec

Every technique, where it fires, and the exact recipe.

One signature technique per act — nothing repeats. Ranges are given in the animation-range syntax so they drop straight into app/globals.css.

Backbone

Native CSS scroll-driven animation carries ~80% of the motion. view() and scroll() run off the main thread — no jank, no listeners, and reduced-motion is a one-line opt-out.

Where GSAP stays

Three orchestrated sequences keep ScrollTrigger: the case-study step scrub, the chained research reveal, and any pinning. Everything else drops its JS.

Already proven here

@supports (animation-timeline: view()) is already used in globals.css for marker-track. The idiom is established — this extends it rather than introducing it.

Rules that hold everywhere

  • Content is legible at rest. Motion is the arrival, never a gate on reading.
  • Author the resting state as the CSS default; animations only travel to it. A timeline that fails to resolve shows a finished page.
  • One easing across the site: cubic-bezier(.16, 1, .3, 1) — already the only curve in globals.css.
  • Scroll-driven animations use linear timing. Easing lives in the keyframe distribution, not the timing function.
  • No technique appears in two acts.
  • Nothing starts before the element is on screen. Every reveal begins at entry 100% — the element fully inside the viewport — never at entry 0–20%, which fires while it is still a sliver at the bottom edge.
  • Anything inside a position: sticky container must ride a named timeline from a non-sticky ancestor. A sticky element's own view() stalls while it is pinned.
  • The rail is the only place with continuously-looping motion (glow, flow, echoes). It is a signal, not decoration — and it is the first thing reduced-motion removes.

Support & fallback

  • Wrap in @supports (animation-timeline: view()); without it the resting state simply shows, no JS shim needed.
  • timeline-scope is the one newer piece — if absent, --night falls back to a per-section static value and the wipe is skipped.
  • offset-path is broadly supported; the packet degrades to its end position.
  • Drop the gsap.registerPlugin import cost on routes that no longer need ScrollTrigger.
